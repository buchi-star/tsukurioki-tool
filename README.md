# 作り置き献立メーカー

## 概要

家にある食材を入力するとAIが作り置きおかず3〜5品を提案するツール。

## 技術スタック

- **Node.js** — サーバー・バックエンド処理
- **Anthropic Claude API** — 献立提案AIエンジン
- **HTML / CSS / JavaScript** — フロントエンドUI

## セットアップ

### 1. 依存パッケージのインストール

```bash
npm install
```

### 2. APIキーの設定

`.env` ファイルをプロジェクトルートに作成し、Anthropic APIキーを記入する。

```
ANTHROPIC_API_KEY=your_api_key_here
```

APIキーは https://console.anthropic.com で取得できる。

### 3. サーバーの起動

```bash
node server.js
```

ブラウザで http://localhost:3000 を開く。

## 使い方

1. テキストエリアに今ある食材を入力する（例：鮭、ブロッコリー、玉ねぎ、卵）
2. 「献立を提案する」ボタンを押す
3. AIが作り置きおかず3〜5品を提案する
4. 各料理の食材・調理器具・作り方・保存日数が表示される

## 制約条件

- 電子レンジ不使用（コンロ・魚焼きグリル・電気圧力鍋のみ）
- 揚げ物なし
- 冷蔵3〜5日保存を前提とした作り置き料理
